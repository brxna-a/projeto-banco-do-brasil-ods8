# Arquivos para subir no GitHub

A pasta deve entrar no repositório com o nome `etapa_3`.

Estrutura:

```text
etapa_3/
├── README.md
├── requirements.txt
├── src/
│   └── analise_exploratoria_etapa3.py
├── notebooks/
│   └── analise_exploratoria_etapa3.ipynb
├── outputs/
│   ├── graficos/
│   └── tabelas/
└── documentacao/
    ├── texto_analise_exploratoria.md
    └── validacao_dados.md
```

Não copiar novamente os CSVs para esta pasta. O código usa os arquivos que já estão em `dados/raw`.

Antes do commit, conferir se a pasta está na raiz do projeto. O script foi escrito considerando exatamente essa estrutura.
